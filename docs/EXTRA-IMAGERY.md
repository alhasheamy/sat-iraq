# إضافة صور درون أو صور أرشيفية خاصة

أضف كائنًا إلى `sources` في `config/extra-imagery.json` وسيظهر تلقائيًا في «مصدر الصورة» وفي «قارن مع» بعلامة 📍، ويطير الخريطة إلى حدوده عند اختياره.

```json
{
  "id": "habur-ehas-c045",
  "title_ar": "درون: موقع EHAS-C045 (دهوك)",
  "tiles": "https://YOUR-HOST/habur/{z}/{x}/{y}.png",
  "scheme": "xyz",
  "bounds": [42.10, 36.70, 42.14, 36.74],
  "maxZoom": 21,
  "attribution": "اسم الجهة المصوِّرة · الترخيص"
}
```

- `scheme`: `xyz` (الافتراضي) أو `tms` إذا كان ترتيب الصفوف مقلوبًا.
- `bounds`: `[غرب, جنوب, شرق, شمال]` لتجنّب طلب بلاطات خارج التغطية.
- يجب أن يبدأ `tiles` بـ `https://` ويحوي `{z}` و`{x}` و`{y}`.

## خطوات لازمة بعد الإضافة
1. أضف نطاق الخادم إلى `img-src` و`connect-src` في `deploy/_headers` ودوّن السبب في `docs/CHANGES.md`.
2. التزم بترخيص البيانات. الموقع غير ربحي، فبعض التراخيص (مثل CC BY-NC) مناسبة وبعضها لا.

## من أين تأتي البلاطات؟
- صورة GeoTIFF (أورثوموزاييك) من الدرون: `gdal2tiles.py --xyz -z 12-21 input.tif out/` ثم استضف المجلد.
- الاستضافة: Cloudflare R2 أو أي دلو عام. لا تضعها داخل Pages لأن الحد 20,000 ملف.
- رفعها إلى OpenAerialMap (مجاني) يعطيك رابط بلاطات جاهزًا، لكن تحقق من ترخيص الملف أولًا.
